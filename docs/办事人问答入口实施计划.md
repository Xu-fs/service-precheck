# 办事人问答入口实施计划

**Goal:** 按2026-10-30用户确认的接口与事件约定实现移动网页、SQLite会话及POST SSE。
**Architecture:** FastAPI异步入口、SQLAlchemy异步仓储、受控RAG服务；网页与接口同源。
**Tech Stack:** Python 3.11+、FastAPI、SQLAlchemy 2、aiosqlite、原生HTML/CSS/JS。
**Spec:** 本次聊天中已确认的接口设计；既有 docs/设计框架.md 的业务边界继续适用。用户已明确要求确认后给完整代码，本次按此授权直接执行。

## 全局约束
- 不新增顶层目录或第二个源码包，数据库与索引在仓库外。
- 匿名Cookie与登录身份隔离；客户端不得指定所有者。
- 最近6个完整轮次、历史6000字符、依据1800字符、问题2000字符、总输入12000字符上限。
- 校验后输出；固定拒答、事项确认、引用及人工入口不可伪造审批或工单状态。
- 流前统一JSON错误，流后error事件；SQLite短事务及幂等、并发租约。

## 检查重点
1. 猜测会话ID或只换登录Cookie不能读取其他身份记录。
2. 同一幂等键重试不重复写库，切换事项不能复用旧事项的结果或历史依据。
3. 流中取消、模型故障和进程重启不能遗留永久处理中状态。
4. 中文SSE跨数据块、恶意HTML和失败恢复不会破坏页面。
5. 没有模型密钥或个体工商户指南时如实提示，不冒充真实模型或正式功能。
