# 办事人问答入口运行说明

## 当前交付

FastAPI异步问答入口、SQLite会话/消息/引用、匿名隔离、独立账号登录、事项确认、POST SSE、手机单页、上下文裁剪和异常恢复。回答采用校验后的教学原文分段输出，前端有打字机效果；不是将未经校验的模型token直接展示。

当前只配置居住证教学指南，个体工商户事项返回无依据提示。没有材料识别、材料预检、人工工单、工作人员规则管理、真实政务接口和正式审批能力。真实模型服务尚未联调，不能据自动化测试声称实际模型效果达标。

## 启动

在仓库根目录执行，Python 3.11+：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:PYTHONPATH = (Resolve-Path src).Path
.\.venv\Scripts\python.exe -m zhengwu_precheck.main
```

访问 [本机聊天入口](http://127.0.0.1:8000)。默认只监听本机，可用 `--port` 修改端口。`--check` 只检查依赖，不启动服务。

若ensurepip失败且虚拟环境没有pip，可用 `python -m pip --python .venv install -r requirements.txt` 安装。本次本机为Python 3.12.10。

## 模型及运行数据配置

模型设置沿用 [阶段1说明](阶段1指南问答原型.md)：

```powershell
$env:LLM_PROVIDER = 'openai-compatible'
$env:LLM_BASE_URL = 'https://approved-model.example/v1'
$env:LLM_MODEL = 'YOUR_CHAT_MODEL'
$env:EMBEDDING_BASE_URL = 'https://approved-embedding.example/v1'
$env:EMBEDDING_MODEL = 'YOUR_EMBEDDING_MODEL'
$chatSecret = Read-Host '聊天服务密钥' -AsSecureString
$env:LLM_API_KEY = [System.Net.NetworkCredential]::new('', $chatSecret).Password
$embeddingSecret = Read-Host '嵌入服务密钥' -AsSecureString
$env:EMBEDDING_API_KEY = [System.Net.NetworkCredential]::new('', $embeddingSecret).Password
```

示例地址须替换为客户批准的真实地址。LLM支持兼容聊天协议与Ollama原生聊天协议；嵌入使用兼容 `/embeddings` 协议。只有本机服务允许HTTP及省略密钥。模型未配置时页面仍可选择事项，实际居住证问答返回503中文说明，不生成虚假答案。

默认不继承操作系统代理环境；若客户批准通过代理访问服务，可设 `ZHENGWU_TRUST_PROXY_ENV=true`，使用SOCKS代理时另装 `httpx[socks]`。不在仓库或URL中写密钥。

| 环境变量 | 默认值／用途 |
| --- | --- |
| ZHENGWU_RUNTIME_DIR | 系统临时目录下zhengwu-web；SQLite及FAISS位于其中，稳定使用时设为仓库外私有目录 |
| ZHENGWU_GUIDE | 仓库data内的居住证教学指南；本期固定对应居住证事项 |
| ZHENGWU_ALLOWED_HOSTS | localhost,127.0.0.1,[::1],testserver；远程部署设置实际域名 |
| ZHENGWU_SECURE_COOKIES | false供本机HTTP演示；HTTPS部署设为true |
| ZHENGWU_HUMAN_SERVICE | 未配置真实联系方式的中文提示；可替换为获确认的窗口咨询方式 |
| RAG_INPUT_CHAR_LIMIT | 默认12000，最大12000；按实际模型能力调整，仍预留输出预算 |
| ZHENGWU_TRUST_PROXY_ENV | false，是否显式继承HTTP代理环境 |

运行目录应由服务账号控制，禁止映射到公开静态路径。不使用真实材料。默认临时目录可能被系统清理；30天匿名Cookie和8小时登录会话期限不是业务资料留存政策。知识文档或模型配置变更后重启服务；同名嵌入模型实际版本改变时还应删除自己生成的旧索引后重建，或使用新的运行目录。

首期单进程运行，限流状态及索引锁位于进程内。多进程、高并发、正式留存处置和生产数据库迁移尚未实现。反向代理应禁用SSE缓冲，配置请求体大小和可信转发地址，并正确转发协议及Host。

## 创建独立账号

公开咨询无需账号。需要登录验证时，维护人员在同一个运行目录配置下执行：

```powershell
.\.venv\Scripts\python.exe scripts/create_user.py your_username
```

密码交互输入两次，至少12字符，不显示在命令行参数或日志中。没有默认账号、通用密码或用户自助注册。登录后个人会话与匿名历史分开保存；退出登录可回到同一浏览器原有的匿名咨询。

## 数据及实现边界

SQLite版本1创建问答子集：users、auth_sessions、conversations、messages、message_citations、audit_logs、schema_versions。会话所有者为用户或匿名凭证哈希，二者互斥。表关系沿用此前设计，未提前创建未实现材料或工单功能的假数据。

SQLAlchemy异步仓储隔离SQL；迁移其他数据库时保留身份、所有权、事务与幂等接口，并编写显式迁移。当前初始化并非完整的生产迁移工具，不要把已有其他系统数据库直接作为本期数据库。数据库版本不兼容时拒绝启动。

Cookie、密码哈希、SQLite SQL均由后端处理，前端只保存会话UUID。问答历史不自动附带任何个人材料或业务记录。接口协议、错误码及SSE事件详见 [接口说明](api.md)。

## 验证命令

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
node --test tests/test_sse.mjs
node --check src/zhengwu_precheck/static/js/chat.js
python scripts/check_structure.py
```

浏览器验证需要额外安装playwright并具备本机Chrome：

```powershell
.\.venv\Scripts\python.exe -m pip install playwright
.\.venv\Scripts\python.exe -X utf8 tests/run_browser_check.py
```

测试运行器使用随机本机端口及明确的模型替身，独立测试账号只存在于测试临时数据库；不作为产品服务。退出时结束自己启动的进程树，避免Windows启动器遗留子进程。截图和报告在已忽略的 `.venv/browser-results/`。若受限执行环境阻止Windows asyncio创建本机自通信连接，测试可能停在事件循环初始化；本次通过允许本机I/O的执行环境完成验证。测试临时文件写入受限时可仅在测试终端将TEMP、TMP设为已忽略的 `.venv/tmp`。
