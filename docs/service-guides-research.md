## 身份证补办页可采用的内容

1. **适用情形**：居民身份证丢失的，应申请补领；严重损坏不能辨认的属于换领情形。[S1，第十一条]
2. **申请材料的法律依据**：法律第十条规定申请领取时填写《居民身份证申领登记表》、交验居民户口簿；具体补领、异地受理以及线上办理的可用证明和核验方式，应按拟办理地公安机关的现行办事指南核对，不能由该条直接推导全国补领一律只需户口簿。[S1，第十条]
3. **身份信息核验**：申请领取、换领、补领居民身份证应登记指纹信息。页面可以提示按受理窗口要求完成信息核验与采集；不能据此断言全国所有补领均必须首次重新采集，也不能承诺全部可以在线完成。[S1，第三条]
4. **通用办理路线**：先核对拟办理地公安户政办事指南、确认受理方式及材料，再按要求申请、核验信息，并依受理凭证安排领取。这是基于上述法定程序的整理指引，不是已经接入的在线申领服务。[S1，第三、十、十一、十二条]
5. **法定发放期限**：自提交《居民身份证申领登记表》之日起六十日内发放；交通不便的地区可以适当延长，延长不得超过三十日。这是法律期限，不是当地当前承诺的实际制证时间，不得改写为“六十个工作日”。[S1，第十二条]
6. **急需用证**：在申请领取、换领、补领期间急需使用居民身份证的，可以申请领取临时居民身份证。具体方式依公安机关现行规则。[S1，第十二条]

## 便民场馆开放页可采用的内容

| 类别 | 可写入页面的事实 | 依据 |
| --- | --- | --- |
| 公共图书馆 | 文献信息查询、借阅，阅览室、自习室等公共空间设施场地开放，以及公益性讲座、阅读推广、培训、展览应免费提供 | S2，第三十三条 |
| 图书馆开放公告 | 应通过网站或其他方式公告服务内容、开放时间和借阅规则；除不可抗力外，闭馆或更改开放时间应提前公告 | S2，第三十八条 |
| 图书馆节假日 | 公休日应开放，国家法定节假日应有开放时间；不据此推导全天开放或固定钟点 | S2，第三十八条 |
| 文化馆、文化站及基层文化中心 | 公益性文化单位创造条件提供免费或优惠的演出、展览、阅读、艺术培训等服务；基层综合性文化服务中心提供阅读、艺术普及和群众性文化体育活动等 | S3，第十四、二十九、三十条 |
| 公共体育场馆等公共文化设施 | 根据其功能和特点，按国家有关规定免费或优惠开放；不能承诺所有项目、全部时段均免费 | S3，第十四、三十一条 |
| 各类场馆信息公示 | 管理单位应公示服务项目和开放时间，临时停止开放应及时公告 | S3，第三十一条 |

### 建议页面呈现

- 按“公共图书馆”“文化馆与文化站”“公共体育场馆”分区展示服务类型。
- 将“开放时间”写为查看拟前往场馆最新公告，明确未提供具体城市及场馆实时排期。
- 将“预约方式”写为出发前核对场馆官方公告是否要求预约、活动报名、借阅登记或分时入场；这是出行检查建议，不声称全国统一强制预约。
- 将“费用”写为核对公告列出的免费或优惠服务项目，区分图书馆法定免费基本服务与其他场馆具体项目。
- 不虚构场馆名称、开放钟点、预约余量、街道位置和联系电话；不显示拨号、地图和导航入口。
