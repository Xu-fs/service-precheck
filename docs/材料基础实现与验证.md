# 材料基础实现与验证（第二批独立模块）

日期：2026-10-31。范围：材料存储、授权、版本集合、辅助预检、受限本地教学提取。未修改既有居住证指南或公开知识索引。用户资料不进入公开知识库。

## 接口与调用约定

`MaterialRepository(engine, runtime_dir, clock=time.time, processor=None)` 使用现有异步SQLAlchemy引擎。`runtime_dir` 必须是仓库外的私有持久目录；测试使用隔离临时目录。Windows上线需为服务账号设置私有ACL。

全部仓储方法为异步：

- `initialize()`：可重入建表，保留原有记录。
- `store(user_id, case_id, filename, content: bytes, consent: bool)`：case_id为本人conversations.id；最多10份有效材料、每份10MB，只接收签名匹配的PNG/JPEG/PDF；授权必须精确为True。返回元数据，不返回本地路径。
- `get(user_id, material_id)`、`read_bytes(user_id, material_id)`、`list(user_id, case_id)`：归属和当前授权校验；读取原件同时核对SHA256。
- `correct_fields(user_id, material_id, expected_version, kind, fields)`：版本比较后保存主动转录；来源明确为user_transcription，不能冒称OCR。kind为identity/residence/application/business_address。字段仅允许name/address/date/expiry_date/historical_valid_on。
- `revoke(user_id, material_id)`：撤回授权、清空当前转录并删除原件；既有集合和预检立即不可继续使用。删除失败应由上层记录并安排安全重试，不展示成功。
- `create_set(user_id, case_id, material_ids)`、`get_set(user_id, material_set_id)`：冻结原件哈希、版本、来源、字段；使用时复核当前授权和版本。
- `process(user_id, material_id)`：默认明确不可用；仅可信虚构教学场景以processor={trusted_teaching: True}运行真实本地识别。提取后必须人工确认，OCR不会自动填充已确认字段。
- `precheck(user_id,case_id,matter_id,scenario_id,rule_snapshot_id,material_set_id,expected_case_version)`：rule_snapshot_id接收服务端不透明选择快照ID，记录为selection_snapshot_id。实际教学规则独立加载，记录teaching_rule_version=teaching-2026-10-v1及teaching_rule_digest（文件字节SHA256），返回逐项证据和私有记录ID。
- `get_precheck(user_id, precheck_id)`：只允许本人读取，重新校验材料集合有效性和当前教学规则文件摘要。

**集成责任：** 调用precheck和使用其结果前，路由/智能体服务必须校验有效事项确认、当前case版本及规则快照。此仓储仅记录expected_case_version，不代替上层案例选择校验。个人材料用于工单时，仍须另行选择共享范围并确认提交。指南公开发布仍走已有审核发布流程；教学清单夹具不等于已获批准政策。

## 真实识别与处理限制

本次实际安装在已忽略的.venv：rapidocr-onnxruntime 1.4.4、Pillow 13.0.0、pypdfium2 5.14.0；OCR中文ONNX模型随依赖包置于.venv，无外部材料传输。运行依赖清单由集成负责人统一更新。

本地worker在解析前设置Windows Job Object：单进程、30秒CPU、1.5GB进程内存、关闭作业时结束进程。父进程最多60秒（默认40秒），超时/取消均kill并wait回收。图片最多1200万像素、单边8000、拒绝多帧；PDF使用pypdf解压工作预算和页数上限。OCR响应含行位置、置信度及待核对标记。

**尚未满足的生产前置条件：** Job Object不隔离文件权限或网络访问，因此默认不解析不受信任材料，只开放明确可信虚构教学识别。生产须增加并验证低权限账号/容器的文件访问和出站网络限制，再讨论开放解析。文本PDF可提取；扫描PDF和混合PDF的无文本页使用pypdfium2按2倍比例渲染后真实本地OCR，渲染前限制像素数量，逐页释放。不将这些限制记作已全部完成。

## 教学指南种子资料启用步骤

1. 原始30题评测使用独立冻结知识库，继续保留data/居住证申领_教学指南.md原件、DEMO-2026-01版本及原索引，不能在变更知识库后沿用原答案评分。
2. 在独立教学运行库，以有knowledge.manage和相应事项权限的工作人员进入`/staff/knowledge/new`，分别上传`data/materials/居住证申领_教学指南_v1.md`与`data/materials/个体工商户设立登记_教学指南_v1.md`。对应事项/情形分别为residence-permit/rental-demo和sole-trader-registration/standard-demo；kind=guide，is_teaching=true，rule_version=teaching-2026-10-v1，来源填写相应仓库相对路径。两事项分别建文档，不能把合并说明当作单事项知识上传。
3. 等待索引就绪，检查提取片段与教学标注；通过详情页提交审核，再由具有对应审核及发布权限的工作人员审核、发布。浏览器表单复用CSRF与岗位权限。不得写数据库跳过审核，不自动发布。
4. 规则/清单可用相应事项的规则维护入口分别保存为教学版本并经历相同审核发布。机器清单JSON目前作为本地解释规则夹具加载，不表示已通过真实政策签核。
5. 新发布快照及教学规则文件摘要进入新的事项选择确认；两事项另建评测版本。事项/规则更新后重新确认和预检，旧预检不得继续作为当前结论。

## 处理进程回收补充验证

修复Windows虚拟环境启动器转发问题：使用实际基础解释器`sys._base_executable -I`启动，仅注入可信虚拟环境依赖和源码目录。这样即使worker尚未建立Job Object，超时/取消结束的也是实际解析进程。父进程在finally执行kill及受保护的wait；输出按块读取并限制200KB，拒绝无效JSON、类型不符、越界置信度、页数/正文超限和错误的confirmed标记，返回统一失败而不泄露正文。

补充测试先以子进程自身PID就绪标记观察到旧启动器PID不同，修复后验证超时和取消均回收同一实际解释器；没有使用任意等待时长模拟就绪。异常输出测试实际启动本地进程写入无效/超大输出，未模拟业务返回。最终23项材料聚焦测试全部通过，耗时22.824秒，包含真实PNG和扫描PDF中文OCR复验。

- PASS：实际解释器PID与被管理进程一致，超时后进程已结束。
- PASS：取消在进程报告就绪后触发，返回前完成实际进程回收。
- PASS：无效JSON、数组/null、错误字段类型、伪造已确认结果统一失败。
- PASS：50万字节输出被200KB读取预算截断并结束子进程。
