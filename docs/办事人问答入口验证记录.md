## 已解决的验证问题

1. 普通受限环境阻止Windows asyncio的本机自通信连接；堆栈定位到socketpair初始化，改用允许本机I/O的执行环境验证，没有绕过业务权限检查。
2. 失效匿名Cookie更新时曾导致页面令牌与Cookie不同，回归复现403后修复。
3. 共享逻辑提取时CLI曾漏导入load_chunks，完整回归发现后补齐。
4. 本机代理环境含未安装支持库的SOCKS配置；模型客户端改为默认直连获批准地址，代理需显式启用。
5. Windows通用测试服务辅助脚本及解释器启动器会遗留子进程；专用运行器使用随机端口并只清理自己启动的进程树，最终浏览器运行及清理退出码0。
